Corrections

Help us correct the record

Include the article or project link, the exact detail that needs correcting, your proposed correction and a supporting source if available. Distinguish a factual correction from a different interpretation.

Review before publication

A correction request is a request for editorial review. It does not automatically change an article or a map record. Evidence may support a correction, a clarification or an explicit note that accounts conflict.

The current contact route is a public GitHub issue and requires a GitHub account. Do not include private information. A private editorial email address has not yet been configured.
