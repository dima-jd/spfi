Accessibility

Using SPFI

Use the Skip to content link to move past navigation. On small screens, separate buttons open the main menu and editorial sections. Keyboard users can move through links and controls with Tab; Escape closes article and map dialogs. The map has a list alternative.

Language and motion

English and Hebrew controls set the reading direction. Some imported evidence remains in its source language. The organisations carousel has a pause control. Browser zoom and reduced-motion preferences can help tailor the reading experience.

Known limits and feedback

Accessibility work is ongoing; this page is not a claim of audited standards compliance. External documents and map tiles may have limitations we cannot control. Report the page URL, affected control, browser and assistive technology where relevant, and the task you could not complete.

The current contact route is a public GitHub issue and requires a GitHub account. Do not include private information. A private editorial email address has not yet been configured.
